Modern Legacy heroes should use polished, contemporary 2.5D children’s game art with strong silhouettes, expressive faces, dynamic poses, and diverse representation. Keep turquoise/aqua, warm gold-orange, and deep navy as the dominant palette so the collection remains visually tied to the Little Champs logo.

**Why:** The user explicitly approved the first modern shield-hero concept and its optimistic futuristic city background on September 12, 2026.

**How to apply:** Use this direction when proposing or generating replacements for the star-unlocked Legacy collection. Show concepts before integrating them unless the user explicitly requests implementation.
