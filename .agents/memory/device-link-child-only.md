---
name: Device Link ist nur für Kinder
description: Produktentscheidung zur Rollenbegrenzung von Device Link
---

Device Link darf ausschließlich Kinderprofile authentifizieren. Eltern sollen sich mit einem eigenen Konto registrieren oder regulär anmelden; ein PIN-/Gerätelink ersetzt kein Elternkonto.

**Why:** Die Elternrolle über Device Link führte zu wiederholt auftauchender Onboarding-Tour. Der Nutzer entschied sich bewusst für eine klare Trennung und übernimmt die Rückstellung des einzigen bisher so genutzten Profils auf „Kind“ selbst.

**How to apply:** Ein verknüpftes Kind darf nicht zur Elternrolle wechseln, bevor alle aktiven Device-Link-Sitzungen getrennt wurden. Solange es verknüpft ist, statt einer Rollenwahl den Grund und den nötigen Trennschritt anzeigen; auch direkte Änderungsanfragen ablehnen. Andere legitime Eltern-Anmeldewege nicht sperren.
